Ambient Home on a rooted LG TV

Installing Ambient Home and Home Helper from Windows on an LG webOS TV rooted with the Homebrew Channel, done by hand from start to finish, and a record of every change made to the project along the way.

1. What you end up with

  • Ambient Home as the TV's home screen: the living lakeside with the clock and live weather, your app shortcuts and inputs on the first screen, and on the second screen (press Down from Inputs) Stremio's Continue watching and all your apps.
  • The remote's Home button opens Ambient Home (through Home Helper), and the TV opens it by itself when you turn it on.
  • Everything stays up to date by itself: apps you install or remove, devices you plug in, and Stremio's progress. No syncing from the computer.
  • Settings > Running apps: what is running and how much memory it uses, Close, Keep closed (stops LG starting an app in the background), and closing background apps when Ambient Home starts.

2. What you need

  • An LG webOS TV rooted with the Homebrew Channel. This guide was written on an OLED65C34LA (webOS 23, firmware 23.25.40). Developer Mode is not used.
  • A Windows PC on the same network as the TV, with:
    • Git for Windows (git-scm.com), which brings Git Bash and ssh. Run every command in this guide in Git Bash, not in PowerShell or Command Prompt.
    • Node.js 22 or newer (nodejs.org).
    • Python 3 from python.org, with Add python.exe to PATH ticked. (Windows' built-in python3 is only a shortcut to the Microsoft Store; the scripts use python instead.)
  • The TV's IP address: TV Settings > General > Network > your connection. In the commands below, replace TV_IP with it (for example 192.168.1.111). Giving the TV a fixed address in your router saves surprises later.

3. Installation, step by step

1Set up the Homebrew Channel

On the TV, open the Homebrew Channel, then its Settings:

  • SSH Server: on. The computer installs everything over SSH.
  • Telnet: off. Telnet gives anyone on your network root access with no password.
  • Block system updates: on. An LG update can remove root.

The SSH server starts when the TV starts: if it was off, restart the TV after turning it on (unplug it for 30 seconds; the power button only puts it in standby).

Careful with Life's Good Without Spying. With all of its protection on, including Voice, the TV's SSH port stopped answering, and only came back after a purge in that app. If you use it, turn its options on a few at a time and check that SSH still connects after each.

These Life's Good settings were tested with everything in this guide: SSH, Ambient Home, the weather, Stremio's Continue watching and the power-on handling all keep working.

  • On:
    • ACR / Alphonso, SmartAd, Telemetry & crash reports, Home recommendations, App usage uploads, LG Channels, Ads & ACR, Boot purge;
    • LG service platform, together with NTP clock: the clock then comes from internet time, and the LG Content Store won't open until you switch LG service platform off;
    • ThinQ: this stops the LG ThinQ phone app and Alexa.
  • Off:
    • Voice: kept on, so voice search works, for example in Stremio;
    • Content Store, Remote code lookup, Firmware updates (the Homebrew Channel already blocks updates), LAN discovery (it breaks casting), DNS filter.

2Get the project

git clone https://github.com/vapp13/lg-ambient-home.git
cd lg-ambient-home

Every later command runs from this lg-ambient-home folder.

3Install LG's command-line tools inside the project

npm install --prefix tools @webos-tools/cli@3.2.6 --ignore-scripts --no-save --no-package-lock
Check: ls tools/node_modules/.bin | grep ares-install lists ares-install.

4Make an SSH key and give it to the TV

A key lets the scripts log in as root without a password. Make one (press Enter if asked anything):

ssh-keygen -t ed25519 -N "" -f ~/.ssh/lgtv_ed25519

Copy its public half to the TV. Replace TV_IP:

ssh root@TV_IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys" < ~/.ssh/lgtv_ed25519.pub
  • The first time, SSH asks whether to trust the TV (The authenticity of host … can't be established): type yes.
  • It then asks for the TV's root password. On a Homebrew Channel TV it is alpine unless you changed it. Nothing shows while you type. Seeing no output afterwards means it worked.
Check: this prints key works without asking for a password:
ssh -i ~/.ssh/lgtv_ed25519 root@TV_IP "echo key works"
The root password is not something LG's tools set: password= in LG's commands only records the TV's existing password. That is why this guide uses a key and never a password.

5Register the TV with LG's tools

tools/node_modules/.bin/ares-setup-device -a lgtv -i "host=TV_IP" -i "port=22" -i "username=root" -i "privatekey=lgtv_ed25519"
Check: both commands work; the second prints the TV's model and firmware.
tools/node_modules/.bin/ares-setup-device --list
tools/node_modules/.bin/ares-device -i --device lgtv

Seeing root@TV_IP:22 in the list is how the scripts know the TV is rooted and install over SSH. If lgtv already exists (from an earlier try), change it with -m lgtv instead of -a lgtv.

6Restart the TV

Unplug the TV for 30 seconds, then plug it back in. Now that a key is on the TV, the Homebrew Channel stops setting the alpine password at startup: root can only log in with your key.

Check: step 4's echo key works command still works.

7Your own settings (optional)

Personal settings live in prototype/config.local.js, which git ignores. Create it in any text editor, for example with Notepad:

notepad prototype/config.local.js

Paste and adjust (keep only the lines you want):

// Personal settings for this TV. Git ignores this file.
HOME_CONFIG.weather.latitude = 50.72;     // your coordinates, for live weather
HOME_CONFIG.weather.longitude = -1.88;
HOME_CONFIG.media.show = false;           // no demo Continue watching row (Stremio's still shows)
HOME_CONFIG.home.show = false;            // no demo Home Assistant row
HOME_CONFIG.allAppsShortcut = false;      // no All apps icon in the Apps row (Down still opens All apps)

The All apps shortcut can also be switched later in Ambient Home's Settings.

8Install Ambient Home

bash scripts/tv-preview.sh

This builds Ambient Home, uploads it over SSH, installs it with the TV's own installer, opens it, and puts the root scripts on the TV (see How it works). The TV's installer sometimes takes up to three minutes; the script waits.

Check: Ambient Home opens on the TV. Within about 10 seconds your real apps and inputs appear, and within a minute Stremio's Continue watching (on the second screen) fills in if Stremio is signed in on the TV.

9Install Zig (for Home Helper)

Home Helper has two small C programs, compiled here from source with Zig, installed inside the project:

python -m venv tools/venv && tools/venv/Scripts/pip install ziglang==0.14.1

10Install Home Helper and take over the Home button

TV_HOST=TV_IP bash scripts/tv-home.sh install

A prompt appears on the TV asking to let Home Helper see which app is on screen and whether the TV is on: accept it with the remote (it disappears if you press another button; if that happens, run the command again). The installer may take a few minutes.

Then switch the Home button to Ambient Home:

bash scripts/tv-home.sh start
bash scripts/tv-home.sh status
Check: status says Helper is running; Home opens Ambient Home, and the Home button on the remote opens Ambient Home.

11Restart once, so the TV starts into Ambient Home

Once Home is set to Ambient Home (step 10), the startup script tells LG's boot service to open Ambient Home when the TV is switched on. LG's boot service only reads that as the TV starts, so unplug the TV for 30 seconds and plug it back in once.

Check: turn the TV off with the remote and on again. You see LG's start-up cover with Ambient Home's logo and Loading, then Ambient Home, with no input or LG Home first.

Only the remote's power button, the TV's own button and a cold start are sent to Ambient Home. A console turning the TV on over HDMI-CEC, a network wake-up and the Netflix button still go where LG sends them. Handing Home back to LG (Home three times, Settings, or bash scripts/tv-home.sh lg) takes it off from the next start, and so does choosing LG's choice in Settings > When the TV turns on.

LG's own Home Auto Launch setting (Settings > General > System > Additional Settings > Home Settings) no longer matters for the power button. It was switched off on this TV while testing, before this method was found.

5. Final check

Unplug the TV for 30 seconds and plug it back in, then:

bash scripts/tv-home.sh status
ssh -i ~/.ssh/lgtv_ed25519 root@TV_IP "ps | grep [t]v-root-live; tail -n 5 /tmp/ambient-home-live.log"
Expected: Helper is running and Home opens Ambient Home; tv-root-live.js is running; the log shows the app list and Continue watching being updated. Telnet should refuse connections (port 23 closed).

7. Troubleshooting

SSH times out (Connection timed out on port 22)

  • Check SSH Server is on in the Homebrew Channel's Settings, then restart the TV properly (unplug 30 seconds): the SSH server only starts at boot.
  • If the TV answers on the network but port 22 silently drops connections, something is blocking it. In our case it was Life's Good Without Spying; a purge in that app brought SSH back.
  • A TV in standby does not answer SSH: turn the picture on.

The TV rejects the root password when copying the key

The password is the TV's existing root password (alpine on a fresh Homebrew Channel). If you typed something else into an earlier ares-setup-device … password= command, that did not change the TV's password.

Home opens LG Home

  • bash scripts/tv-home.sh status. Home pressed three times means Helper was stopped on purpose: bash scripts/tv-home.sh start.
  • Settings in Ambient Home says Home Helper is not installed: run bash scripts/tv-preview.sh once, which reinstalls the startup script and runs it.

Installing seems stuck

The TV's installer sometimes takes up to three minutes, then finishes. If a run was interrupted, run the same command again.

Continue watching is empty

  • Stremio must be installed and signed in on the TV. The list refreshes every minute (from Stremio's server every 5 minutes).
  • Check the log (Everyday commands) for lines starting Stremio library.
  • Opening a card opens Stremio: LG's Stremio app ignores links to a title, so it starts on its home, where the same title is in the same place in its own Continue watching.

An app I kept closed came back

Keep closed switches off LG's preloading and closes the app 15 seconds after it is off screen. An app that comes straight back three times in ten minutes is left alone for ten minutes, rather than closed in a loop.

8. How it works on the TV

Everything runs as Developer Mode-style apps plus two small root scripts that the Homebrew Channel starts. Nothing in LG's firmware is changed, and scripts/tv-home.sh remove takes it all off.

On the TVWhat it does
/media/developer/apps/…/com.local.ambienthomeAmbient Home (web app) and its small service com.local.ambienthome.service.
/media/developer/apps/…/com.local.nativehomeHome Helper: watches the remote and opens Ambient Home on Home.
/var/lib/webosbrew/init.d/50-ambient-home
(from scripts/tv-root-boot.sh)		Run as root by the Homebrew Channel at every boot. Puts back safe file permissions (LG's devmode.conf makes /media/developer world-writable at boot, and Helper refuses to start like that); lets Ambient Home's service see Helper's folder (its jail sees only its own folder otherwise); creates the request folder for Running apps; starts the live script; starts Helper if Home is set to Ambient Home.
/var/lib/webosbrew/ambient-home/tv-root-live.jsRoot, Node 16. Every 10 seconds: the TV's apps and inputs (with icons) for Ambient Home and Helper; running apps and memory; Keep closed. Once a minute: Stremio's Continue watching. Answers Running apps requests (refresh, close, keep closed, close background apps) and opens Ambient Home at power-on. Log: /tmp/ambient-home-live.log.
/var/lib/webosbrew/ambient-home/tv-root-stremio.jsReads the Stremio app's own sign-in from the TV's web storage (LevelDB) and asks Stremio's server for the library. The sign-in key stays in that process; Ambient Home gets only titles, pictures and progress (stremio.json).
/var/lib/webosbrew/ambient-home/keep-closed.jsonApps kept closed, and those whose preloading was switched off by Keep closed (switched back on when you turn it off).
/home/root/.ssh/authorized_keysYour SSH key.

Ambient Home's service only accepts calls from Ambient Home, and the root script only accepts four requests from it: refresh, close an app, keep an app closed, close background apps. It never closes Ambient Home, LG Home or Home Helper.

9. Every change made

In vapp13/lg-ambient-home, which grew from Chandra-K-Pendyala/ambient-home, starting from its main at Add a weekly forecast and Ambient Wallpaper.

Installing on a rooted TV, from Windows

  • scripts/tv-lib.sh (new), shared by the install scripts:
    • detects a TV registered as root;
    • installs packages over SSH with webOS's own installer, because LG's ares-install fails there with Unable to exec;
    • reads the installer's progress through a terminal, because luna-send prints nothing into a pipe;
    • falls back from rsync, python3 and shasum, which Windows lacks.
  • scripts/tv-preview.sh and scripts/tv-home.sh:
    • use tv-lib.sh;
    • put the root scripts on a rooted TV and repair permissions after each change;
    • find Zig in a Windows venv;
    • remove also removes the root scripts;
    • a fresh copy of the project takes Helper's app list from the TV.
  • scripts/tv-root-boot.sh (new): the startup script described in How it works.
  • scripts/tv-root-live.js (new):
    • the live list of apps and inputs, and the running apps;
    • Keep closed, using LG's preload policy plus a watchdog that backs off;
    • opening Ambient Home at power-on;
    • a 200-line log.
  • scripts/tv-root-stremio.js (new): a small LevelDB and Snappy reader for Stremio's sign-in, and Continue watching from Stremio's library.
  • home-service/service.js: appRequest, which passes Running apps requests to the root script as files in the service's state folder.
  • README: a Rooted TV (Homebrew Channel) section, plus Windows notes. scripts/fix-ipk.py and helper/README.md: Mac-only wording removed.

Ambient Home itself

  • The help bar (preview controls) no longer shows on the TV.
  • Settings' weather location shows your coordinates instead of always "Not set".
  • Demo rows can be hidden with show: false.
  • The second screen holds All apps (and Continue watching), and scrolls.
  • The All apps shortcut is a setting.
  • Hold OK on an app: move, add to or remove from the Home screen, hide. This works in the Apps row and in All apps, and with the Magic Remote. Settings > Hidden apps brings hidden apps back.
  • Apps keep their places when hidden or reinstalled.
  • The idle screen setting is kept across restarts.
  • Inputs: rename and hide. Unused inputs are hidden until something is connected; Settings > Inputs can show all.
  • Live updates from the TV's list: the Inputs row in place; a reload once for new apps.
  • Stremio's Continue watching row, with pictures and progress. Opening a card opens Stremio.
  • Tall cards like Settings keep a margin and scroll.
  • Settings > Running apps: Close, Keep closed, Close all background apps, and close background apps when Ambient Home starts.
  • Power-on straight into Ambient Home: the startup script writes /var/luna/preferences/bootd.json, a copy of LG's /etc/palm/bootd.json whose power-on table sends the power button, the TV's own button and a cold start to Ambient Home (the method Hearth uses). It opens behind LG's start-up cover. Only a copy written by the script is ever replaced or removed.
  • Recent apps (Back on the Apps row) and Uninstall in an app's menu, from the root script, which keeps the history and removes apps with webOS's installer.
  • A splash picture (prototype/splash.png, made from splash.svg) shown while Ambient Home starts from scratch, replacing the grey placeholder. LG's full-boot cover shows only the app's name.
  • Smoother start-up: the scene starts still and its animations begin once two half-second samples reach 50 fps (12 seconds at most); the first draw skips layout-forcing fades; the second screen is built 1.5 s after load; the root script runs Ambient Home's page at CPU priority -5 while it is on screen. Measured on the TV: load in 0.45 s instead of 0.81 s, 36 to 52 fps instead of about 5 between 1 and 4 seconds, 60 fps after. Settings > Animations: Full, Reduced or Off.
  • Faster start: no grey splash screen (noSplashOnLaunch), and the second screen is built just after the page loads, so it loads in about 1 second instead of 4.

Changes on the TV outside the project

  • Homebrew Channel: SSH Server on, Telnet off. Root logs in with the SSH key only; the alpine password stopped working after the first restart with a key.
  • /var/luna/preferences/bootd.json, written by the startup script (see above). LG setting Home Auto Launch: off. The original values were saved on the TV in /var/lib/webosbrew/ambient-home/settings-before-test.json.
  • LG Channels kept closed (its preloading is switched off through Keep closed), and Netflix kept closed. Six LG apps hidden in Ambient Home. All of these are changeable from Ambient Home's Settings.

10. What we learned about the TV

  • LG's ares-install uploads fine over the Homebrew Channel's SSH, then fails with Unable to exec. Installing with luna://com.webos.appInstallService/dev/install works.
  • luna-send prints nothing when its output is a pipe, and does not notice that a subscription has ended. Run it under script (a terminal), or over ssh -tt.
  • At every boot, /etc/init/devmode.conf runs chmod -R 777 /media/developer. The Homebrew Channel's init.d scripts run after it, which is where the fix goes.
  • A dev app's service runs in a jail that only sees its own folder; a bind mount made at boot shows it another one.
  • Web pages can't list or close apps. com.webos.applicationManager/running is denied to them; root can use it, and closeByAppId works for every app except LG Home, which ignores it.
  • The preload manager restarts apps a few seconds after they close: com.webos.service.preloadmanager, with getPreloadPolicy and setPreloadPolicy {"application":{"id":…,"isEnabled":false}}. LG keeps the policy across restarts.
  • The TV closes every app in standby. At power-on, LG opens LG Home (Home Auto Launch on) or the last input (off; it only accepts real inputs there). Without a splash screen, webOS shows a web app once its page has fully loaded.
  • LG's boot service chooses the first app by why the TV was switched on: common.firstAppByPowerOnReason in /etc/palm/bootd.json (here remoteKey, localKey and upDownKey, all "last app"), and it reads /var/luna/preferences/bootd.json instead when that file exists. An app named there opens behind LG's start-up cover (com.webos.app.cpcover). The reason for the last start: luna://com.webos.service.tvpower/power/getPowerOnReason.
  • LG's start-up cover cannot show a picture. After a full start (unplugged, or a restart), the app named in the boot table opens behind CoverUI (/usr/lib/qml/CoverUI, drawn by the surface manager): a black screen with the app's title and "Loading", launched with noSplash: true. It ignores splashBackground, and it is shown before the Homebrew Channel's startup scripts run. From standby there is no cover at all. Ambient Home's own splash picture shows when it starts from scratch at other times.
  • There is no setting for the Home button's app on this TV: general.defaultApps has no home entry, and LG Home is the system's home through its own appinfo.json.
  • LG's Stremio app ignores contentTarget deep links (stremio:///detail/…, #/metadetails/… and web links all open its home page). Stremio's server accepts requests from the TV (CORS *).
  • The TV's web inspector (port 9998) can run JavaScript in Ambient Home's page, which is handy for testing.
